## What the survivors mean

All three A* heuristic mutants changed the distance function in a way that still returns *a* path:
the "Heuristic Functions" tests only assert `result.success === true` and `totalCost > 0`. A wrong
heuristic is therefore invisible. This is not a harness failure — the canary failed 24 of 32 tests,
so the instrument can see red. It is a genuine question about the fixtures: none asserts a numeric
heuristic value or a known-optimal path cost.

Concrete next step: add direct assertions for the five exported heuristics (for example
`manhattanDistance({x:0,y:0}, {x:3,y:4}) === 7`) and a known-optimal-cost path, then re-run this
spec. A mutant that is currently `SURVIVED` must become `DETECTED` before the gap is closed.
